# SmileCare Dental Website

SmileCare Dental is a responsive multi-page dental clinic website created as a business website demo. The website is designed for a fictional dental clinic and includes common sections that a real clinic website may need, such as services, team members, appointment booking, contact details, pricing, FAQs, and Google Maps location.

## Website Pages

The website includes the following pages:

- Home
- Services
- Our Team
- Contact

## Features

- Responsive website design
- Multi-page layout
- Dental services section
- Team member profile cards
- Appointment booking form
- WhatsApp contact button
- Treatment price guide
- FAQ section
- Google Maps embed
- Footer with quick links and contact information
- Clean and professional clinic-style design
